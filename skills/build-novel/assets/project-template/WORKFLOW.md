# Workflow

## Current phase

Intake.

## Drafting authorization

Not granted.

## Chapter review

Draft, revise the same text, then verify continuity before advancing.

## Block review

Define block boundaries after the chapter outline is accepted.

## Reader-accessibility pass

Run after the complete draft and before general editorial revision. Reorient after gaps, present functions before labels, reduce accidental concept load, and preserve intentional mystery and technical texture.

## General review

Review by scene, continuity, character arc, reveal schedule, prose patterns, and reader feedback.

Run a dedicated emotional turning-point pass for deaths, betrayals, irreversible losses, and major revelations. Search dialogue blocks for repeated question-answer mismatch patterns, especially “I didn't ask that” exchanges.

## Advanced revision

When structural diagnosis is uncertain: baseline blind panel, structural revision, continuity and surgical editing, final blind panel, then production. Skip the baseline panel when the problem and remedy are already clear.
